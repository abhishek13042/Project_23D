# Reports

Evidence from the runs. Numbers in the documentation must trace back to a file here.

| Path | Holds | Source |
|---|---|---|
| `data/` | Staging, prepare and preprocessing run records | Copied from Kaggle |
| `training/` | Pilot and training session records | Copied from Kaggle |
| `evaluation/results.md` | The headline results | Generated by `scripts/report/build_report.py` |
| `evaluation/spec004/` | Per-case scores, summaries, case analysis (after the run) | Copied from Kaggle |
| `release/model_card.md` | What the model is and how it may be used | Written by hand |

Don't edit `evaluation/results.md` by hand. Rerun the report builder instead.
