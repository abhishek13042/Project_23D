# Kaggle notebooks

These notebooks are generated by `scripts/notebooks/`, so don't edit them by hand. See
[docs/development.md](../docs/development.md#how-the-notebooks-work). They run in this order:

| Notebook | Kaggle kernel | Spec | Hardware | Purpose |
|---|---|---|---|---|
| `00_stage_data_{1,2,3}.ipynb` | `kits23-stage-1..3` | 001 | CPU | Download and verify KiTS23 |
| `01_prepare_data.ipynb` | `kits23-prepare-data` | 002 | CPU | Verify, split, plan |
| `01b_preprocess_{1..4}.ipynb` | `kits23-preprocess-1..4` | 002 | CPU | Preprocess one quarter of the cases each |
| `02_train_pilot.ipynb` | `kits23-train-pilot` | 003 | GPU | 5-epoch check and timing |
| `02_train.ipynb` | `kits23-train-1`, `-2`, ... | 003 | GPU | 100 epochs over resumable sessions |
| `03_evaluate.ipynb` | `kits23-evaluate` | 004, 005 | GPU | Test-set score and case analysis |

The kernels are private because of the KiTS23 license. Inputs and settings for each one are in
[docs/reproduce.md](../docs/reproduce.md).
