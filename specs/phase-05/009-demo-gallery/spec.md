# SPEC 009 — Demo Gallery

- **Status:** DONE, except publishing to Hugging Face, which needs the owner's account
- **Phase:** 5 — Public demo
- **Depends on:** SPEC 004, SPEC 005, SPEC 008, D-018

## 1. Purpose

Give every visitor something real to explore, with no backend. The gallery holds about 10
pre-computed test cases, shown as CT, prediction and ground truth together.

This is the part of the demo that must always work.

## 2. Case selection

Cases are chosen from the SPEC 005 analysis by a rule written in code, so the choice can't be
steered towards flattering examples.

| Group | Cases | Why |
|---|---|---|
| Best | 1–2 | Shows what good looks like |
| Median | 2–3 | Shows the typical result |
| Worst | 2 | Shows failure honestly |
| Small tumor | 1–2 | The hardest group |
| With cyst | 1–2 | Tumor and cyst are told apart |

## 3. Deliverables

| File | Content |
|---|---|
| `scripts/gallery/select_cases.py` | Applies the selection rule to the case analysis |
| `scripts/gallery/build_gallery.py` | Crops and packages each case |
| `notebooks/04_gallery.ipynb` | Runs both on Kaggle, generated by `scripts/notebooks/` |
| Hugging Face dataset | The packaged cases and a dataset card |

Each case contains `ct.nii.gz`, `pred.nii.gz`, `gt.nii.gz` and `meta.json`.

## 4. Requirements

- `S009-REQ-001`: Each case is cropped to the kidney region plus a margin.
- `S009-REQ-002`: Each case is at most 40 MB. The largest, case_00540, needs 30.4 MB.
- `S009-REQ-003`: `meta.json` holds the case ID, the region scores from `per_case.csv`, the selection group and the region volumes.
- `S009-REQ-004`: CT, prediction and ground truth of one case share a shape and an affine.
- `S009-REQ-005`: The gallery uses the evaluated predictions, not a new inference run.
- `S009-REQ-006`: The dataset card states CC BY-NC-SA 4.0, the KiTS23 citation, the crop and "not for clinical use".

## 5. Tests

- The selection rule on a fake analysis, including the worst group.
- Cropping keeps labels and updates the affine correctly.
- The packaged scores equal the values in `per_case.csv`.

## 6. Acceptance criteria

- [x] About 10 cases are built, and publishing waits on the account, and the worst group is included.
- [ ] One case loads in a NiiVue test page from the Hugging Face URL, which also proves CORS works.
- [x] Total size is under about 300 MB.

## 7. Non-goals

- Publishing the full dataset. KiTS23 stays private on Kaggle.
- Uncropped scans.
